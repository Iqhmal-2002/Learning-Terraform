# Hashicorp Terraform
Company specializing in managed open-source tools to support development and deployment of large-scale service-oriented software installations

HCP
Unified platfrm access to Hashicorp's product
HCP services are cloud agnostic
Support for main cloud service provider (CSP) - AWS, GCP, Azure
Highly suited for multi-cloud workloads

Hashicorp Products
Boundary - remote access to system based trusted identity
Consul - service discovery platform. provides full featured service mesh for secure segmentation across cloud or runtime env and distributed key-storage for application configuration
Nomad - scheduling and deployment of task across worker nodes
Packer - building vm images for deployment
terraform - IaC software for provisioning and adapting infrastructure across all major cloud provider
Vagrant - building and maintenance of reproducible software-development environments via virtualization technology
Vaul - secret management, identity based access, encrypting application data
Waypoint - modern workflow to build, deploy and release across platforms
