# Setting up multi cloud provider
Only need 1 required_provider, alias is only needed if you're referring to the same cloud but with different config like a different region

terraform {
  required_providers {
    azurerm = {
      source  = "hashicorp/azurerm"
      version = "=5.0.0"
    }
    aws = {
      source  = "hashicorp/aws"
      version = "~> 6.0"
    }
  }
}

To connect to aws, use aws configure instead of aws sso
aws sso would need PAYG, aws configure can work with the free version

use region = "ap-southeast-2" because singapore is blocked

ASW instance is Azure VM, Azure resource group has no AWS equivalent
