## 2026-08-27 — Run basics Terraform

**What I did:** 
Started following the command to create terraform and setup Azure subscription.
Somehow it works and created a resource group

**What broke / what confused me:** 
.gitignore does in fact get commited. Needed to create a .env file to paste credentials where git won't track it
But, gitignore is in and of itself a git control system. Anything added here will be ignored in tracking, unless it was added after it was tracked. Then you need to remove it from cache, effectively rolling back the git
Also, github refuses file that are over 100mb, and the bunch of Terraform files are regenerated per initialize so don't track them, especially since they could also contain secrets

Probably run the whole thing in Powershell instead of VS code because the terminal is so small
