# Snippets

Actual runnable scripts. Anything I've typed out more than twice belongs here instead of buried in a markdown code fence.

Example:
Make them executable before running:

```bash
chmod +x snippets/whatever.sh
./snippets/whatever.sh
```

Every script should start with a comment saying what it does and when to use it. 
A script whose purpose I've forgotten is a script I won't run.
